### M1 红线地基

| 组件 | 文件 | 能力 |
|---|---|---|
| 领域模型 | `core/models.py` | Target / Authorization / ScopeEntry / RateEvent / AuditLog |
| 授权门 | `core/gate.py` | 无已确认且在有效期的授权一律拒绝；归档目标拒绝；扫描前检查 include scope |
| Scope 守卫 | `core/scope.py` | scheme 白名单、host 精确/有界后缀匹配、裸 IP 须显式登记、路径排除正则、禁止 userinfo |
| 限速器 | `core/ratelimit.py` | SQLite 持久化令牌桶：每秒上限 + 每日预算，重启不丢失，拒绝时不消耗预算 |
| 审计链 | `infra/audit.py` | 追加写 + sha256 链式 hash；`audit verify` 可检测篡改与重算 hash 伪造 |
| CLI | `app/commands/` | `target add/list/show/archive`、`authz add/confirm`、`scope add-include/add-exclude/list`、`audit tail/verify` |

## 三、红线在代码中的强制点（不可绕过）

1. 任何后续扫描命令必须先经过 `AuthorizationGate.assert_ready_for_scan()`；
2. 任何目标 URL 必须经过 `ScopeGuard.assert_url_allowed()`（M5 会用它反向生成 ZAP context，并丢弃报告中 scope 外的告警）；
3. 任何目标侧请求预算必须经过 `RateLimiter.acquire()`，默认 1 req/s、每日 500；
4. 所有敏感动作（建目标、授权确认、scope 变更、后续扫描启停/拦截）写链式审计；
5. 主动扫描枚举已保留，M2/M5 实现扫描器时该分支直接抛 `FeatureDisabledError`。
